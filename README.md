# Relay-inspired landing page

A responsive React + Vite landing page inspired by the uploaded reference recording. It uses custom CSS for the dark/neon-lime visual system, Framer Motion for subtle motion, and Lucide React icons.

## Requirements

- Node.js 18+ (Node.js 20+ recommended)
- npm

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually `http://localhost:5173`).

## Production build

```bash
npm run build
npm run preview
```

## Customize

- Main page and mock workflow UI: `src/main.jsx`
- Styling, responsive breakpoints, and animations: `src/styles.css`
- Dependencies and scripts: `package.json`

The brand, metrics, integrations, and contact address are demo content. Replace them before publishing.
